Reverse a String

EasyStringsTwo pointers

You’re given a string s. Return the string with its characters in reverse order.

Uppercase and lowercase letters, digits, spaces and punctuation all count as characters, and the case of each letter stays the same.

Example 1
s = "hello"
output: "olleh"
The last character comes first, and the first comes last.
Example 2
s = "CodeForge"
output: "egroFedoC"
Capital letters keep their case, they just move.

Constraints: 1 ≤ s.length ≤ 10⁵, and s only has printable ASCII characters.

Hints

Tap a hint to reveal it.

The last character of the input becomes the first character of the answer.
Walk from the end of the string back to the start, collecting each character as you go.
Or put the characters in an array and swap the first with the last, then move both ends inward.
