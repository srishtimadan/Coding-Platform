Two Sum

EasyArraysHash mapSolved

You’re given an array of integers nums and an integer target. Return the indices of the two numbers that add up to target.

Each input has exactly one solution, and you can’t use the same element twice. The answer can be in any order.

Example 1
nums = [2,7,11,15], target = 9
output: [0,1]
2 + 7 = 9, so we return the indices 0 and 1.
Example 2
nums = [3,2,4], target = 6
output: [1,2]

Constraints: 2 ≤ nums.length ≤ 10⁴, and exactly one valid answer exists.

Hints

Tap a hint to reveal it.

A brute force check of every pair works, but takes O(n²) time.
For each number, you’re really looking for target − number.
Store values you’ve seen in a hash map so each lookup is O(1).
